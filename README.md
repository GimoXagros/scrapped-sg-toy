# Toy

[sungjin-bae/Toy](https://github.com/sungjin-bae/Toy)에서 가져온 Unreal Engine C++ 소스입니다. [Source](Source)에 게임 모듈, 플레이어 컨트롤러, 분대·유닛 관련 코드와 게임·에디터 빌드 대상이 있습니다.

이 체크아웃에는 `.uproject`, `Content`, `Config`가 포함되어 있지 않습니다. 완성된 실행 파일이나 바로 열 수 있는 Unreal 프로젝트 패키지로 취급하지 마세요. 빌드에는 원본 프로젝트 구성과 해당 엔진 환경이 추가로 필요하며 저장소 파일만으로 정확한 엔진 버전을 정할 수 없습니다.
